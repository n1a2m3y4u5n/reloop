# Reloop

음식물 쓰레기를 수거, 자원화, 도시형 스마트팜, 소비로 되돌리는 도시 순환형 푸드 플랫폼 프로토타입입니다.

- 데모: https://reloop.fly.dev
- 수상: 제19회 전국학생창업발명경진대회 창업부 우수상 (한국지식재산보호원장상)
- 수상: 2025 교내 청소년 과학 페어 은상 (2위)

## 소개

음식물 쓰레기를 버리는 데서 끝내지 않고 자원화와 재배, 소비까지 하나의 고리로 잇는 서비스입니다. 소비자 앱과 운영자 관제를 함께 만든 양면 플랫폼이며, 회수기와 수거 차량, 처리 공정은 서버가 시뮬레이션합니다.

## 주요 기능

소비자 앱
- 배출: 로드셀 무게 측정을 시뮬레이션하고 무게에 비례해 포인트를 적립합니다.
- 처리 현황: 배출한 음식물이 수거, 자원화, 스마트팜 재배, 수확, 스토어 순으로 진행되는 과정을 보여 줍니다.
- 스토어: 스마트팜 농작물과 제휴 식품을 포인트로 구매하고 배송을 추적합니다.
- 가정용 BSF 모듈: 집에서 음식물을 투입해 생물전환하고 수확하는 흐름입니다.
- 데이터: 회수기 배출 히트맵, 통계, 단지·개인 랭킹과 챌린지, 개인 환경 임팩트 리포트, 알림이 있습니다.

운영자 관제
- 회수기 적재량을 모니터링하고 수거 차량을 자동 배차합니다. 용량 제약 차량경로 문제를 최근접 이웃과 2-opt로 풉니다.
- 처리 단계별 처리율과 대기열을 기준으로 파이프라인을 운영하고 병목을 감지합니다.

## 기술

- 백엔드: Node.js 내장 `http`, `node:sqlite`
- 프론트엔드: 바닐라 JS SPA (프레임워크·빌드 없음)
- 외부 의존성 없음

```
server.js        API와 서버 틱(시뮬레이션 구동)
db.js            SQLite 스키마, 시드, 상수
ops.js           운영자 레이어 (수거 경로, 처리 파이프라인)
public/          index.html, app.js, visuals.js, styles.css
```

## 실행 방법

Node.js 22.5 이상이 필요합니다. 설치 과정은 없습니다.

```bash
node server.js
# http://localhost:5178
```

처음 실행하면 `reloop.db`를 자동으로 만들고 시드 데이터를 넣습니다.
