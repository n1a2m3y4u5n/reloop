# ♻️ Reloop — 도시 순환형 푸드 플랫폼

음식물 쓰레기를 **수거 → 자원화(BSF 생물전환·전기화학) → 도시형 스마트팜 → 소비**로 되돌리는 도시 순환형 푸드 플랫폼 프로토타입입니다.
사용자 참여(배출)를 출발점으로 수거·자원화·생산·소비를 하나의 고리로 통합한 **양면 플랫폼**(소비자 + 운영자)을 구현했습니다.

> 2026 전국 학생 창업·발명 경진대회 출품작 · 팀 CNSAi

## 실행

외부 라이브러리·설치 과정 없이 **Node.js 하나로** 돌아갑니다 (Node 내장 `http` + 내장 `node:sqlite`).

```bash
node server.js
# → http://localhost:5178
```

> Node 22.5+ 필요 (내장 SQLite 사용). 서버가 처음 켜질 때 `reloop.db`를 자동 생성·시드합니다.

## 주요 기능

**소비자 앱**
- 🗑️ **배출** — 로드셀 무게 측정 시뮬레이션 → 무게 비례 포인트 적립
- 🔄 **처리현황** — 배출한 음식물이 수거→자원화→스마트팜 재배→수확→스토어로 실시간 진행 (+ 자원화 공정 라이브, 도시농장 AI 센서 제어)
- 🛒 **스토어** — 스마트팜 농작물·제휴식품 구매(포인트 내부 환류), 배송 추적
- 🪴 **가정용 BSF 모듈** — 집에서 직접 음식물 자원화(투입→생물전환→수확)
- 📊 **데이터** — 회수기 배출 히트맵 지도, 통계, 단지/개인 랭킹·챌린지
- 🌍 개인 환경 임팩트 리포트, 🔔 알림

**운영자 관제**
- 🛰️ **회수기 관제 + 자동 배차** — 회수기 적재량을 실시간 모니터링하고, 위치·용량을 고려한 **용량제약 차량경로 최적화(최근접 이웃 + 2-opt)**로 수거 차량을 스스로 배차
- ⚙️ **처리 파이프라인 운영** — 각 단계 처리율·대기열 기반으로 전체가 자동 운영되고 병목을 자동 감지

## 구조

```
server.js        API + 서버 틱(모든 시뮬레이션 구동)
db.js            SQLite 스키마·시드 + 상수(거주지 데이터셋 등)
ops.js           운영자 레이어 — 수거 라우팅(VRP) + 처리 파이프라인
public/
  index.html     HTML 껍데기 + 헤더/탭바
  app.js         SPA 로직 (모든 화면·API 연동·폴링)
  visuals.js     애니메이션 SVG 장면
  styles.css     스타일
```

## 기술

- **백엔드** Node.js (내장 http), `node:sqlite`
- **프론트엔드** Vanilla JS SPA (프레임워크·빌드 없음)
- **외부 의존성 0개**
